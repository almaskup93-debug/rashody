# Учёт расходов

Страница для личного учёта расходов. Работает без установки и внешних ресурсов. Данные сохраняются в localStorage текущего браузера; для проверок используйте вымышленные расходы.

## Что умеет
- [Добавлять трату](specs/001-dobavit-tratu.md): сумма, категория, дата, необязательный комментарий; последние добавленные записи сверху, итог текущего месяца.

## Как открыть и проверить
1. Скачайте проект в одну папку и откройте index.html двойным щелчком.
2. Добавьте за текущий месяц 5 000, 2 500 и 12 000 → итог 19 500 ₸.
3. Нажмите F5 → траты и итог остаются.
4. Отправьте пустую сумму, abc, -100, 0, 12,50 → подсказка, список и итог не меняются.
5. На пустом хранилище добавьте 1 250 000 → показано 1 250 000 ₸.
6. Трата прошлого месяца видна в списке, но не меняет итог текущего месяца.
7. Проверьте ширину 375px: нет горизонтальной прокрутки, все поля и кнопки доступны.
