# Добавить трату и показать итог за месяц

## Для кого и зачем
Для одного человека, который записывает личные расходы с телефона или компьютера и хочет видеть траты за текущий месяц.

## Что должно быть
- Форма: сумма, категория, дата и комментарий.
- Категории: Еда, Транспорт, Дом, Другое.
- Сумма обязательна: положительное целое число тенге. Можно вводить пробелы между тысячами, например 5 000. Пустые значения, ноль, отрицательные числа, дроби и текст не сохраняются; рядом с полем появляется понятная подсказка.
- Дата обязательна, по умолчанию — сегодня по местному времени. Комментарий необязателен.
- Кнопка «Добавить» сохраняет корректную трату. Под формой появляется список всех сохранённых трат: последняя добавленная — сверху.
- У каждой траты видны сумма, категория, дата и комментарий, если он заполнен.
- Показан итог за текущий календарный месяц по местному времени. Траты других месяцев остаются в списке, но в этот итог не входят.
- Пока расходов за текущий месяц нет, итог — 0 ₸. Пустой список сопровождается короткой подписью.
- Деньги отображаются целыми тенге с пробелами между тысячами: 15 000 ₸. NaN не появляется.
- Траты сохраняются в localStorage и восстанавливаются после обновления страницы.

## Примеры
1. Добавить за текущий месяц 5 000 ₸, 2 500 ₸ и 12 000 ₸ → три записи в списке, последняя сверху, итог 19 500 ₸.
2. Оставить сумму пустой и нажать «Добавить» → подсказка, новая запись не появляется, итог не меняется.
3. Ввести abc, -100, 0 или 12,50 → подсказка, значение не сохраняется, NaN не появляется.
4. На пустой странице добавить 1 250 000 за текущий месяц → запись и итог показывают 1 250 000 ₸.
5. При итоге за текущий месяц 19 500 ₸ добавить 1 000 ₸ с датой прошлого месяца → запись видна в списке, итог остаётся 19 500 ₸.
6. Добавить расход без комментария → расход сохраняется без обязательного заполнения комментария.
7. После добавления трат нажать F5 → записи и итог восстановлены.
8. Ввести 1 2 3 или 12 34 → подсказка, сумма не сохраняется. Пробелы разрешены только между группами тысяч, как в 1 250 000.

## Ограничения
- Только index.html, styles.css и script.js для приложения; без npm, библиотек и внешних ресурсов.
- Данные хранятся только в браузере; сетевых запросов нет.
- Страница открывается двойным щелчком по index.html.
- Интерфейс на русском, поля и кнопки не меньше 44px по высоте; кнопки также не меньше 44px по ширине. На ширине 375px нет горизонтальной прокрутки.
- В эту функцию не входят редактирование, удаление, фильтры, экспорт и итоги по категориям. Итоги по категориям — отдельное задание урока.
